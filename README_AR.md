# Squad Tasks — المرحلة 1 (الهيكل، قاعدة البيانات، الدخول)

## ما الذي يعمل في هذه المرحلة
- قاعدة بيانات كاملة مع RLS (كل الجداول من المواصفات).
- دخول الأدمن بكود يُتحقق منه في الخادم فقط (أيقونة أعلى يسار الشاشة الرئيسية).
- إنشاء لاعب (اسم + صورة) وتوليد كود دخول فريد، مع نسخ ومشاركة.
- إعادة توليد الكود، إلغاؤه (يُنهي جلسات اللاعب فورًا)، إيقاف/تفعيل اللاعب.
- دخول اللاعب بالكود مع بقاء الجلسة، وبروفايل بسيط وتسجيل الخروج.
- حد للمحاولات الفاشلة (8 محاولات / 15 دقيقة لكل عنوان IP).

الأزرار المعطّلة في لوحة الأدمن مكتوب عليها «قريبًا» وتُفعَّل في المراحل التالية.

## خطوات الإعداد (بالترتيب)

### 1) مشروع Supabase
أنشئ مشروعًا في supabase.com، ثم من Settings > API انسخ:
- Project URL
- مفتاح anon (العام فقط). **لا تستخدم service_role في التطبيق أبدًا.**

### 2) قاعدة البيانات
افتح SQL Editor والصق محتوى الملف
`supabase/migrations/20261029000001_phase1_schema.sql` ثم Run.

### 3) أغلق التسجيل العام (مهم جدًا)
Authentication > Sign In / Providers (أو Settings) > عطّل **Allow new users to sign up**.
بدون هذا الإعداد يستطيع أي شخص إنشاء حساب بمفتاح anon.

### 4) الأسرار (Edge Functions > Secrets)
أضف ثلاثة أسرار:
- `ADMIN_CODE` = كود الأدمن
- `ADMIN_AUTH_PASSWORD` = نص عشوائي طويل (32 حرفًا فأكثر)
- `CODE_PEPPER` = نص عشوائي طويل (32 حرفًا فأكثر) — **لا تغيّره بعد إنشاء لاعبين، وإلا تبطل أكوادهم**

### 5) نشر الدالة
Edge Functions > Create function باسم **squad** بالضبط، والصق محتوى
`supabase/functions/squad/index.ts` ثم Deploy. اترك خيار Verify JWT مفعّلًا.

### 6) إعداد التطبيق
- افتح `lib/config.dart` وضع الرابط ومفتاح anon.
- أنشئ مشروع Flutter جديدًا من قالب Klencod، ثم انسخ `lib/` و`pubspec.yaml` فوق ملفاته.
- **صلاحية الإنترنت:** افتح `android/app/src/main/AndroidManifest.xml` وتأكد أن فيه السطر التالي
  داخل وسم `<manifest>` وقبل `<application>`، وإلا لن يتصل التطبيق بعد بناء نسخة release:

      <uses-permission android:name="android.permission.INTERNET"/>

## اختبارات المرحلة 1 (أخبرني بالنتيجة قبل ما نكمل)
1. كود أدمن خاطئ ← رسالة «الكود غير صحيح».
2. كود أدمن صحيح ← تفتح لوحة الأدمن، وتبقى بعد إغلاق التطبيق وفتحه.
3. إضافة لاعب باسم وصورة ← يظهر كوده مرة واحدة.
4. دخول اللاعب بالكود من حساب/جهاز آخر ← يفتح بروفايله.
5. إلغاء الكود من الأدمن ← يخرج اللاعب عند أول تحديث أو فتح للتطبيق.
6. كود لاعب خاطئ 8 مرات ← رسالة «محاولات كثيرة».
